# 共通基礎 - 理解度チェックテスト

## 📋 概要

各カテゴリの理解度を確認するための自動採点テストです。

## 🚀 使い方

### 1. テストを実行

各カテゴリのディレクトリに移動して実行：

```bash
cd tests/common/01-git-basics
npm install
npm test
```

### 2. 結果の確認

- ✅ **合格**: 次のカテゴリに進んでください
- ⚠️ **惜しい**: 間違えた箇所を復習してください
- ❌ **要復習**: コンテンツを読み直してください
