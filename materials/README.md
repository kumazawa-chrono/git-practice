このディレクトリには、研修の配布用資料（料金表、広告資料など）を格納しています。

- **`pricing-sheet.md`** - 料金表（配布用）
  - 基本コース料金
  - 割引制度
  - 企業研修向け料金
  - 月額制プラン
  - 支払い方法
  - 類似サービスとの比較

- **`promotional-material.md`** - 研修解説の広告資料
  - 研修のコンセプトと特徴
  - カリキュラム構成
  - 料金体系
  - 対象者
  - 技術スタック
  - 学習の流れとサポート体制
  - よくある質問

## 📝 使用方法

これらの資料は、以下の用途で使用できます：

- 営業・セールス資料として
- ウェブサイトへの掲載用
- パンフレット・チラシの作成元
- お客様への説明資料

必要に応じて、PDFやその他の形式に変換してご利用ください。
