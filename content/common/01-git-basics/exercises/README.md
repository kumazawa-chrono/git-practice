# 01. Git基礎 - 実践課題

## 📋 概要

Gitの基本操作を実践を通して身につけます。

## 🎯 学習目標

- [ ] 基本的なGitコマンドを使える
- [ ] ブランチを作成・マージできる
- [ ] Pull Requestを作成できる
- [ ] コンフリクトを解決できる

## 📝 課題一覧

| 課題 | 難易度 | 所要時間 | 内容 |
|------|:------:|:--------:|------|
| [課題1](exercise-01.md) | ⭐ | 30分 | 基本コマンドの練習 |
| [課題2](exercise-02.md) | ⭐⭐ | 45分 | ブランチとマージ |
| [課題3](exercise-03.md) | ⭐⭐ | 60分 | Pull Requestの作成 |

## 🔧 事前準備

```bash
# Gitがインストールされていることを確認
git --version

# ユーザー設定
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```
