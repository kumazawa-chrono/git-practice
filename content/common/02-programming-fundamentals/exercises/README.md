# 02. プログラミング基礎（TypeScript） - 実践課題

## 📋 概要

TypeScriptの基本を実践を通して身につけます。

## 🎯 学習目標

- [ ] TypeScriptの基本構文を使える
- [ ] 関数を定義し、モジュールを分割できる
- [ ] クラスを使ったプログラミングができる
- [ ] 型システムを活用できる

## 📝 課題一覧

| 課題 | 難易度 | 所要時間 | 内容 |
|------|:------:|:--------:|------|
| [課題1](exercise-01.md) | ⭐ | 45分 | 基本構文と関数 |
| [課題2](exercise-02.md) | ⭐⭐ | 60分 | クラスとインターフェース |
| [課題3](exercise-03.md) | ⭐⭐⭐ | 90分 | 型を活用したアプリケーション |

## 🔧 事前準備

```bash
# プロジェクトの作成
mkdir ts-practice
cd ts-practice
npm init -y

# TypeScriptのインストール
npm install typescript ts-node @types/node -D

# 設定ファイルの作成
npx tsc --init

# 実行
npx ts-node index.ts
```
