- クラウドでの本番運用を学びたい
- コンテナオーケストレーション（ECS/Fargate）に興味がある

**学習日数**: 3-4日（選択）

AWSを中心としたクラウドの実践的な使い方を学びます。基礎で学んだ概念を実際のサービスに適用し、コンテナオーケストレーションまで習得します。

## 前提知識

- **必須**: [07. インフラ基礎](../07-infrastructure-basics/) を修了していること
- **推奨**: [11. コンテナ発展](../11-container-advanced/) を修了していること

## なぜ学ぶ必要があるのか

### この技術が解決する問題

```mermaid
flowchart TB
    subgraph local[ローカル環境]
        A[Docker Compose]
    end
    
    subgraph cloud[クラウド本番環境]
        B[ECS/Fargate]
        C[ロードバランサー]
        D[オートスケーリング]
        E[監視・ログ]
    end
    
    local -->|デプロイ| cloud
```

ローカルから本番へ：

- **スケーラビリティ**: 負荷に応じた自動スケール
- **可用性**: 複数AZでの冗長構成
- **運用**: ログ収集、監視、アラート

### 実務での重要性

- **クラウドは標準**: ほとんどのサービスがクラウド上で動作
- **コンテナ運用**: Kubernetes/ECSでのコンテナ管理が主流
- **インフラコスト**: 適切な設計でコストを最適化

## 技術の歴史的背景

```mermaid
timeline
    title AWS コンテナサービスの進化
    2014 : ECS登場
    2017 : Fargate登場 サーバーレスコンテナ
    2018 : EKS登場 マネージドKubernetes
    2020 : App Runner登場
```

- **2017年**: AWS Fargateリリース
- **特徴**: サーバー管理不要のコンテナ実行
- **利点**: インフラ管理の負荷を大幅削減
