## 🎯 なぜこれを学ぶのか

AIから良い出力を得るには、良い入力（プロンプト）が必要です。プロンプトの書き方を学ぶことで、AI活用の効果が大幅に向上します。

## 📚 学習内容

### 1. プロンプトの基本構造

```
[コンテキスト] + [タスク] + [制約/フォーマット]
```

#### 例

```
# コンテキスト
TypeScriptとExpressを使ったAPIサーバーを開発しています。

# タスク
ユーザー登録APIのエンドポイントを作成してください。

# 制約/フォーマット
- POST /api/users
- 入力: name, email, password
- zodでバリデーション
- エラーハンドリングを含める
```

### 2. 具体性の重要性

```
❌ 曖昧なプロンプト
「ログイン機能を作って」

✅ 具体的なプロンプト
「Express + TypeScriptで、以下の仕様のログインAPIを作成してください:
- エンドポイント: POST /api/auth/login
- リクエストボディ: { email: string, password: string }
- パスワード検証: bcryptを使用
- 成功時: JWTトークンを返す（有効期限1時間）
- 失敗時: 401エラーとメッセージ
- 既存の@src/models/User.ts を使用」
```

### 3. 効果的なテクニック

#### Few-shot（例を示す）

```
以下の形式でAPIレスポンスを生成してください:

例:
{
  "success": true,
  "data": { ... },
  "message": "User created successfully"
}

エラーの例:
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid email format"
  }
}

これに従って、商品取得APIのレスポンスを実装してください。
```

#### Chain of Thought（段階的に考えさせる）

```
このバグを修正してください。
まず、以下のステップで分析してください:
1. エラーメッセージの意味
2. 原因となりそうな箇所
3. 修正方法
4. 修正コード
```

#### ロールの指定

```
あなたはシニアTypeScript開発者です。
以下のコードをレビューし、改善点を指摘してください。
パフォーマンス、可読性、保守性の観点でお願いします。
```

### 4. コードレビュー依頼

```
このコードをレビューしてください:

確認してほしい観点:
- [ ] セキュリティ（SQLインジェクション、XSSなど）
- [ ] パフォーマンス
- [ ] エラーハンドリング
- [ ] TypeScriptの型の適切さ
- [ ] 可読性

問題があれば、修正案も示してください。
```

### 5. デバッグ依頼

```
以下のエラーが発生しています。原因と解決策を教えてください。

エラーメッセージ:
```
TypeError: Cannot read property 'map' of undefined
```

関連コード:
[コードを貼り付け]

試したこと:
- console.logでdataを確認 → undefinedだった
```

### 6. プロンプトテンプレート

#### 新機能実装

```
## 背景
[機能の目的や背景]

## 要件
- [要件1]
- [要件2]

## 技術スタック
- [使用技術]

## 参考ファイル
@[関連ファイルパス]

## 出力形式
[期待する形式]
```

#### リファクタリング

```
このコードをリファクタリングしてください。

改善したい点:
- [改善点1]
- [改善点2]

制約:
- [制約1]
- [制約2]

現在のコード:
[コード]
```

### 7. よくある失敗と対策

| 失敗 | 対策 |
|------|------|
| 出力が期待と違う | より具体的に指示 |
| コードが動かない | エラーメッセージを共有して修正依頼 |
| 古い情報 | 使用バージョンを明記 |
| 長すぎる出力 | 範囲を限定 |

## ✅ まとめ

| ポイント | 内容 |
|---------|------|
| 構造 | コンテキスト + タスク + 制約 |
| 具体性 | 曖昧さを排除 |
| 例示 | Few-shotで期待を明確に |
| 段階的 | 大きなタスクは分割 |
