## 🎯 なぜこれを学ぶのか

CursorはAIファーストのコードエディタで、この研修のメインツールです。効果的に使いこなすことで、開発効率が大幅に向上します。

## 📚 学習内容

### 1. Cursorとは

**VS CodeベースのAIファーストIDE**

- VS Codeの拡張機能が使える
- AIがコードベース全体を理解
- チャット、インライン編集、Composer

### 2. 主な機能

#### Chat（⌘K または Ctrl+K）

ファイルやコードを選択してAIに質問。

```
使い方:
1. コードを選択
2. ⌘K
3. 質問を入力
```

#### Composer（⌘I または Ctrl+I）

複数ファイルにまたがる変更を生成。

```
使い方:
1. ⌘I でComposerを開く
2. やりたいことを説明
3. 生成されたコードを確認
4. Accept で適用
```

#### インライン編集

コード中で直接編集を依頼。

```
使い方:
1. コードを選択
2. ⌘K
3. 「この関数をリファクタリングして」
```

### 3. 効果的な使い方

#### コンテキストを与える

```
❌ 悪い例
「ログイン機能を作って」

✅ 良い例
「Express + TypeScriptで、JWTを使った
ログインAPIを作成してください。
- POST /api/login
- emailとpasswordを受け取る
- bcryptでパスワード検証
- JWTトークンを返す」
```

#### @ でファイルを参照

```
@src/models/user.ts を参考に、
@src/services/userService.ts の
createUser関数を実装してください。
```

| ショートカット | 機能 |

### 5. 実践例

#### 関数の生成

```typescript
// 「ユーザー配列から重複メールを除去する関数」と依頼

function removeDuplicateEmails(users: User[]): User[] {
  const seen = new Set<string>();
  return users.filter(user => {
    if (seen.has(user.email)) {
      return false;
    }
    seen.add(user.email);
    return true;
  });
}
```

### 6. ベストプラクティス

```
✅ 良い使い方
- 具体的な指示を出す
- コンテキストを与える（@参照）
- 生成結果を必ずレビュー
- 段階的に依頼する

❌ 避けるべき使い方
- 曖昧な指示
- 生成結果を検証せずに使う
- 大きすぎる変更を一度に依頼
- 機密情報を含める
```
