## 🎯 目標

AIと協働して機能を実装し、レビュー・修正を行う。

## 📝 課題内容

### シナリオ: ブックマーク機能の実装

URLブックマーク機能をAIと協働して実装してください。

### Step 1: 要件を整理（自分で）

以下を考えてください:
- どんなデータが必要か
- どんな操作が必要か
- エラーケースは何か

### Step 2: AIにコード生成を依頼

型定義とサービスの生成を依頼してください。

```
以下の仕様でブックマーク機能を実装してください:

型:
- Bookmark: id, url, title, description?, tags[], createdAt

操作:
- 追加（URL必須、タイトル自動取得をシミュレート）
- 削除
- 一覧取得
- タグでフィルター
- 検索（タイトルとURLで）

技術:
- TypeScript
- メモリ上で管理
- zodでバリデーション
```

### Step 3: 生成コードをレビュー

以下の観点でレビューしてください:

```
□ 入力バリデーションは適切か
□ エラーハンドリングはあるか
□ 型は適切か（anyがないか）
□ エッジケースは考慮されているか
  - 空のURL
  - 重複URL
  - 存在しないIDの削除
```

### Step 4: 問題を修正

レビューで見つけた問題をAIに修正依頼、または自分で修正してください。

### Step 5: テストを追加

AIにテストコードを生成させ、動作を確認してください。

### 提出物

1. 生成されたコード（型定義、サービス）
2. レビュー結果（問題点と修正内容）
3. テストコード
4. 振り返り（AIの活用で良かった点、課題）
