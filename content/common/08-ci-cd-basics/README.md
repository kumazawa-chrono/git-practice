# 08. CI/CD基礎

## 概要

**学習日数**: 1-2日

開発を効率化するためのCI/CD（継続的インテグレーション/継続的デリバリー）を学びます。GitHub Actionsを使った自動テスト、自動デプロイについて理解します。

## なぜ学ぶ必要があるのか

### この技術が解決する問題

```mermaid
flowchart LR
    subgraph manual[手動]
        A[テスト実行忘れ]
        B[デプロイミス]
        C[時間がかかる]
    end
    
    subgraph cicd[CI/CD]
        D[自動テスト]
        E[自動デプロイ]
        F[高速]
    end
```

### 実務での重要性

- **品質向上**: プルリクエストごとに自動テスト
- **リリース速度**: 自動デプロイで素早くリリース
- **ヒューマンエラー削減**: 自動化でミスを防ぐ
