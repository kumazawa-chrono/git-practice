## なぜ学ぶ必要があるのか

### C/C++が解決する問題

組み込みシステムでは、リアルタイム性と省メモリが重要です。C/C++はこれらの要件を満たします。

## C言語の基本

### 変数と型

```c
int number = 42;
float temperature = 25.5;
char letter = 'A';
```

### 関数

```c
int add(int a, int b) {
    return a + b;
}
```

### ポインタ

```c
int value = 42;
int *ptr = &value;  // ポインタ
*ptr = 100;         // 値の変更
```
