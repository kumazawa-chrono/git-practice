## 提出方法

### 1. ブランチを作成

```bash
git checkout -b feature/exercise-[カテゴリ番号]-[カテゴリ名]
```

### 2. 課題に取り組む

`exercises/[コース]/[カテゴリ番号]-[カテゴリ名]/` ディレクトリに成果物を作成してください。

```
exercises/
└── [コース]/
    └── [カテゴリ番号]-[カテゴリ名]/
        ├── README.md      # この課題ファイル
        ├── [成果物1]
        └── [成果物2]
```

### 3. コミット

```bash
git add .
git commit -m "feat: [カテゴリ名]の実践課題を完了"
```

### 4. プッシュ

```bash
git push origin feature/exercise-[カテゴリ番号]-[カテゴリ名]
```

### 5. プルリクエストを作成

GitHubでプルリクエストを作成してください。

#### PRテンプレート


## 評価基準

| 項目 | 配点 | 内容 |
|------|------|------|
| 機能 | 40% | 要件を満たしているか |
| コード品質 | 30% | 可読性、命名、構造 |
| テスト | 20% | テストが書かれているか |
| ドキュメント | 10% | コメント、README |

提出後、GitHub Actionsで自動テストが実行されます。

- ✅ テストが通過: メンターレビューに進みます
- ❌ テストが失敗: エラーを確認して修正してください
